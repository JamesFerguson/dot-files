# Session todos: put the number in the subject

Start every session todo's subject with `#N - `, where N is the number the task tools gave it: `#99 - Create a Fat Zebra Australia portfolio in staging`.

- **TaskCreate assigns the number,** so create the todo, then rename it at once with TaskUpdate to add the prefix.
- **Keep the prefix through renames:** a subject change keeps the same `#N - ` at the front.
- **Add it to any todo that lacks it** when you next touch the list.
- Refer to a todo by that number when James can see it.

**Why:** the Claude Code TUI doesn't show todo numbers, so "todo #99" in a reply meant nothing on screen until James asked which one it was.
